# India Runs by Redrob AI — Hackathon Brief

Source-of-truth facts for this project. Captured from the official event
page (https://hack2skill.com/event/india_runs/) on 2026-06-17. **Verify
against the live page before relying on dates** — event details can change.

## What it is

A nationwide innovation challenge by **Redrob AI** + **Hack2skill**.
Free to enter, three tracks, ₹50 Lakh+ total prize pool. We are targeting
**Track 1**.

## Track 1 — The Data & AI Challenge ("Intelligent Candidate Discovery")

Prize pool: **₹10 Lakhs**. Eligibility: AI/ML engineers, data scientists,
developers, search & retrieval specialists, LLM practitioners. Teams of up
to 4 (or solo).

**Problem statement (paraphrased from the official page):**
> Recruiters must find the perfect fit from oceans of profiles, but
> traditional keyword filters are not cutting it. Build a system that moves
> beyond surface-level keywords to deeply understand context, predict
> relevance, and transform massive talent pools into precise, actionable
> shortlists.

**Core objective — intelligently rank candidates by:**
- **Deep Job Understanding** — interpret complex job descriptions
- **Contextual Relevance** — semantic fit beyond keywords
- **Signal Integration** — profile attributes, career metadata, behavioral signals
- Deliver "a lightning-fast, highly accurate, and expertly ranked shortlist"

**Submission requirements:**
- Complete GitHub repository with the code implementation
- Clear documentation / README explaining methodology and architecture
- A **ranked output file in a predefined format** with the candidate shortlist
  (format defined by Redrob — watch for the dataset/spec drop)

## The other tracks (not our focus)

- **Track 2 — Ideathon** (₹30 L): pitch-deck-based; AI systems architecture,
  AI growth strategy, or everyday-AI ideas. No code required.
- **Track 3 — Social Media Challenge** (₹10 L): content creation; the
  "Hiring Heroes" theme overlaps our domain if we want secondary exposure.

## Positioning note

Track 1 is judged primarily on **ranking quality / relevance**, not fairness.
FAIMR's fairness audit is a *differentiator* we layer on top — see Gap G in
`GAP_ANALYSIS.md`. Lead with accuracy; pitch fairness as the
enterprise-ready, EEOC-defensible moat.
